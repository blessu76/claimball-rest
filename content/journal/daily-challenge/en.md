The Daily Challenge is one match a day with a twist, and it has grown over several test builds. They are not released to the public yet.

## One match, one twist

Each day you get a single attempt. The twist changes from a set of variants, so the match is never quite the same twice in a row. It arrived in build 5.

## Fairer rematches

In build 6 we re-balanced the Daily Challenge rematches so the toughest pairings are no longer nearly impossible or nearly automatic.

## If the app closes

Build 7 handles the awkward cases. If the app closes in the middle of a Daily Challenge, you get that day's one attempt back. Leaving to the menu on purpose still uses it up. The system Back gesture or button during a Daily Challenge now pauses and resumes the match, and from other screens it takes you back to the menu instead of closing the app.

## What is next

Claimball is still in testing and coming soon to iOS and Android. There is no release date yet.
