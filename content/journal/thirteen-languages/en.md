Claimball is a game you can play with almost no reading, but menus, hints and rules still need words. This post is about how the language list grew in the test builds. They are not released to the public yet.

## Nine, then thirteen

Build 3 brought the game to nine languages: English, Korean, Japanese, Simplified and Traditional Chinese, Spanish, Brazilian Portuguese, German and French. Build 10 added four more: Indonesian, Russian, Arabic and Hindi.

## Longer words, right-to-left text

Longer words no longer spill out of their boxes, and Arabic keeps its correct order in a right-to-left layout.

## A check that keeps translations safe

Build 14 added an automatic check that keeps the translations safe and complete in all 13 languages, so a missing line is caught before a build goes out.

## What is next

Claimball is still in testing and coming soon to iOS and Android. There is no release date yet. Every build is listed on the [release notes](/releases/) page.
