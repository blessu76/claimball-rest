A fast ball game does not sound easy to play with a screen reader, so we spent build 14, a TestFlight internal test build, on accessibility. It is not released to the public yet.

## VoiceOver

The game screen can now be read aloud with VoiceOver, so every part of a match is announced.

## Large text and small screens

When you raise the text size in your system settings, or play on a small phone, the layout no longer gets cut off or overflows. The same pass made the layout fit iPad and other tablets properly.

## Still ahead

Accessibility is not a one-time task. We will keep testing with these settings turned on as the game grows.

## What is next

Claimball is still in testing and coming soon to iOS and Android. There is no release date yet.
